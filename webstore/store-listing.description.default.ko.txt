웹사이트에서 읽기 어려운 글꼴을 원하는 일본어 글꼴로 자동 교체하는 확장 프로그램입니다.
10종의 글꼴(본문용 7종 + 고정폭용 3종)에서 고를 수 있으며, 설정은 팝업에서 간단히 바꿀 수 있습니다.
사이트가 지정한 읽기 어려운 글꼴만 골라 교체하므로, 사이트의 레이아웃을 크게 흐트러뜨리지 않고 글자를 읽기 쉽게 만들어 줍니다.

특징

・글꼴 선택
  본문용 7종과 고정폭용 3종 중에서 팝업에서 원하는 글꼴을 고를 수 있습니다.
  본문 글꼴은 두께(Regular / Medium)도 선택할 수 있습니다. 설정은 자동으로 저장됩니다.

・켜기/끄기 전환
  팝업의 스위치로 확장 프로그램을 사용 또는 사용 안 함으로 전환할 수 있습니다.

・설치만 하면 자동 교체
  지원하는 사이트에서는 페이지를 열기만 하면 글꼴이 자동으로 교체됩니다.
  문서 작성, 디자인, 코드 편집, 채팅 등 일부 온라인 서비스는 편집 조작감과 아이콘 표시를 지키기 위해 대상에서 제외됩니다. 브라우저 설정 화면처럼 확장 프로그램이 동작할 수 없는 페이지도 대상이 아닙니다.

・본문과 고정폭을 구분하여 교체
  본문에 쓰이는 고딕체, 명조체, 로마자 글꼴은 본문 글꼴로, 코드 등에 쓰이는 고정폭 글꼴은 고정폭 글꼴로 교체합니다. 코드의 자릿수 정렬은 유지되며, 굵은 글씨(Bold)는 굵게 표시됩니다.

・표시가 흐트러지지 않도록 배려
  아이콘 글꼴로 그려진 아이콘이나, 입력란·편집기처럼 글자를 편집하는 부분에는 본문 글꼴을 강제로 적용하지 않습니다.

・최신 웹에도 대응
  open / closed Shadow DOM 안이나 페이지 내 프레임에도 교체를 적용합니다(YouTube 같은 웹 앱도 지원).

・표시에 미치는 영향을 줄인 설계
  선택한 조합에 맞는 스타일을 미리 준비해 두고, 페이지 로드가 시작될 때 적용합니다.

・문의하기
  팝업에서 이메일 인증을 거쳐 개발자(Kagayoi Support)에게 문의를 보낼 수 있습니다.

선택할 수 있는 글꼴

본문 글꼴(7종)
・IBM Plex Sans JP(기본값) … IBM의 디자인 시스템용 글꼴. 가독성과 현대적인 인상을 함께 갖췄습니다.
・Noto Sans JP … Google이 만든 글꼴. 다양한 굵기를 지원하며 어떤 크기에서도 아름답게 표시됩니다.
・M PLUS 2 … 약간 넓고 둥근 디자인. 부드럽고 친근한 인상입니다.
・M PLUS Rounded 1c … 둥근 획 끝이 특징인 둥근 고딕. 부드럽고 친근한 표정입니다.
・Murecho … 직선적이고 깔끔한 디자인. UI나 대시보드와 잘 어울립니다.
・Zen Kaku Gothic New … 전통적인 고딕체의 분위기를 살리면서 현대적으로 다듬은 글꼴.
・LINE Seed JP … LINE이 개발한 글꼴. 둥글고 친근하며 읽기 쉬운 디자인.

고정폭 글꼴(3종)
・UDEV Gothic JPDOC(기본값) … 탁점·반탁점을 구별하기 쉬워 코드 가독성이 뛰어납니다.
・PlemolJP … 프로그래밍과 일본어 모두에 최적화되어 있습니다.
・Moralerspace Neon JPDOC … 코딩용으로 디자인된 합성 고정폭 글꼴입니다.

본문 글꼴은 Regular (400)와 Medium (500) 중에서 두께를 선택할 수 있습니다(기본값: Regular).
LINE Seed JP는 Medium을 선택해도 Regular로 표시됩니다.
고정폭 글꼴은 Regular (400)로 고정됩니다. 굵은 글씨(Bold)는 그대로 유지됩니다.

교체 방식

・본문 → 선택한 본문 글꼴
  사이트가 지정한 일본어 고딕체·명조체와 로마자 및 시스템 기본 글꼴을 선택한 본문 글꼴로 교체합니다. 읽기 어려운 명조체도 가독성 높은 글꼴로 바뀌므로 긴 글도 편안하게 볼 수 있습니다.

・고정폭·코드 → 선택한 고정폭 글꼴
  사이트가 지정한 고정폭 글꼴이나 코드 표시 부분을 선택한 고정폭 글꼴로 교체합니다. 기술 블로그의 코드 블록 등도 읽기 쉬워집니다.

・교체 글꼴에 포함되지 않은 문자(아랍 문자나 태국 문자 등)는 브라우저가 사이트가 지정한 원래 글꼴로 자동 전환하여 표시합니다.

사용 방법

1. 브라우저 도구 모음(확장 프로그램 메뉴)에서 팝업을 엽니다.
2. 본문 글꼴, 본문 두께, 고정폭 글꼴을 선택합니다.
3. 설정은 자동으로 저장됩니다. 설정을 바꾸거나 켜기/끄기를 전환한 뒤에는 열려 있는 페이지를 새로고침하면 반영됩니다.

번들 글꼴은 모두 확장 프로그램 패키지에 포함되어 있으며, 글꼴을 외부에서 불러오지 않습니다.
