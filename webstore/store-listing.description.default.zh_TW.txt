這是一款擴充功能，可自動將網站上難以閱讀的字體替換為您喜歡的日文字體。
可從 10 種字體（7 種內文字體 + 3 種等寬字體）中選擇，並能在彈出視窗中輕鬆變更設定。
它只針對網站指定的、難以閱讀的字體進行替換，因此不會大幅破壞網站版面，同時讓文字更容易閱讀。

特色

・字體選擇
  可在彈出視窗中從 7 種內文字體和 3 種等寬字體裡選擇喜歡的字體。
  內文字體還可以選擇字重（Regular / Medium）。設定會自動儲存。

・開關切換
  透過彈出視窗中的開關，可啟用或停用擴充功能。

・安裝後自動替換
  在支援的網站上，只要開啟頁面，字體就會自動替換。
  部分用於文件編輯、設計、程式碼編輯、聊天等的線上服務，為了保護編輯手感和圖示顯示，不在替換範圍內。瀏覽器設定頁面等擴充功能無法執行的頁面同樣不在範圍內。

・區分內文與等寬字體進行替換
  內文使用的黑體、明朝體和西文字體會替換為內文字體，程式碼等使用的等寬字體會替換為等寬字體。程式碼的字元對齊維持不變，粗體（Bold）仍以粗體顯示。

・盡量避免破壞顯示效果
  對於用圖示字體繪製的圖示，以及輸入框、編輯器等用於編輯文字的區域，不會強制套用內文字體。

・支援現代網頁
  在 open / closed 的 Shadow DOM 內以及頁面內的框架中也會套用替換（也支援 YouTube 等網頁應用程式）。

・減少對顯示的影響
  會預先準備好與所選組合對應的樣式，並在頁面開始載入時套用。

・聯絡我們
  可在彈出視窗中，經電子郵件驗證後向開發者（Kagayoi Support）發送諮詢。

可選擇的字體

內文字體（7 種）
・IBM Plex Sans JP（預設） … IBM 設計系統使用的字體。兼顧可讀性與現代感。
・Noto Sans JP … Google 出品。支援多種字重，在任何字級下都能清晰美觀地顯示。
・M PLUS 2 … 字形略寬且帶有圓潤感。給人柔和親切的印象。
・M PLUS Rounded 1c … 筆畫末端為圓形的圓體黑體。表情柔和親切。
・Murecho … 線條平直、簡潔的設計。與 UI 和儀表板搭配效果良好。
・Zen Kaku Gothic New … 保留傳統黑體的風格，並以現代方式呈現的字體。
・LINE Seed JP … LINE 開發的字體。圓潤、親切且容易閱讀。

等寬字體（3 種）
・UDEV Gothic JPDOC（預設） … 容易區分濁點和半濁點，程式碼可讀性出色。
・PlemolJP … 同時針對程式設計和日文做了最佳化。
・Moralerspace Neon JPDOC … 為程式設計而設計的合成等寬字體。

內文字體可在 Regular (400) 和 Medium (500) 之間選擇字重（預設：Regular）。
LINE Seed JP 即使選擇 Medium，也會以 Regular 顯示。
等寬字體固定為 Regular (400)。粗體（Bold）維持不變。

替換的原理

・內文 → 所選的內文字體
  網站指定的日文黑體、明朝體，以及西文和系統預設字體，都會替換為所選的內文字體。難以閱讀的明朝體也會換成辨識度高的字體，因此閱讀長文更加舒適。

・等寬、程式碼 → 所選的等寬字體
  網站指定的等寬字體和程式碼顯示部分，會替換為所選的等寬字體。技術部落格中的程式碼區塊等也會更容易閱讀。

・替換字體中不包含的字元（如阿拉伯文字、泰文等），瀏覽器會自動切換為網站指定的原字體來顯示。

使用方法

1. 從瀏覽器工具列（擴充功能選單）開啟彈出視窗。
2. 選擇內文字體、內文字重和等寬字體。
3. 設定會自動儲存。變更設定或切換開關後，重新整理已開啟的頁面即可生效。

所有內建字體都包含在擴充功能的安裝包中，不會從外部載入字體。
