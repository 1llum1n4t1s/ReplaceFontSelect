웹사이트에서 읽기 어려운 글꼴을 Noto Sans JP와 UDEV Gothic JPDOC로 자동 교체하는 확장 프로그램입니다.
사이트가 지정한 읽기 어려운 글꼴만 골라 교체하므로, 사이트의 레이아웃을 크게 흐트러뜨리지 않고 글자를 읽기 쉽게 만들어 줍니다. 글꼴을 고를 필요 없이 설치만 하면 바로 사용할 수 있습니다.

특징

・설치만 하면 자동 교체
  지원하는 사이트에서는 페이지를 열기만 하면 글꼴이 자동으로 교체됩니다.
  문서 작성, 디자인, 코드 편집, 채팅 등 일부 온라인 서비스는 편집 조작감과 아이콘 표시를 지키기 위해 대상에서 제외됩니다. 브라우저 설정 화면처럼 확장 프로그램이 동작할 수 없는 페이지도 대상이 아닙니다.

・켜기/끄기 전환
  팝업의 스위치로 확장 프로그램을 사용 또는 사용 안 함으로 전환할 수 있습니다.

・본문과 고정폭을 구분하여 교체
  본문에 쓰이는 고딕체, 명조체, 로마자 글꼴은 Noto Sans JP로, 코드 등에 쓰이는 고정폭 글꼴은 UDEV Gothic JPDOC로 교체합니다. 코드의 자릿수 정렬은 유지되며, 굵은 글씨(Bold)는 굵게 표시됩니다.

・표시가 흐트러지지 않도록 배려
  아이콘 글꼴로 그려진 아이콘이나, 입력란·편집기처럼 글자를 편집하는 부분에는 본문 글꼴을 강제로 적용하지 않습니다.

・최신 웹에도 대응
  open / closed Shadow DOM 안이나 페이지 내 프레임에도 교체를 적용합니다(YouTube 같은 웹 앱도 지원).

・표시에 미치는 영향을 줄인 설계
  교체용 스타일을 미리 준비해 두고, 페이지 로드가 시작될 때 적용합니다.
  배포 패키지에는 이 버전에서 사용하는 글꼴만 들어 있습니다.

・문의하기
  팝업에서 이메일 인증을 거쳐 개발자(Kagayoi Support)에게 문의를 보낼 수 있습니다.

교체 방식

・본문 → Noto Sans JP(Regular)
  사이트가 지정한 일본어 고딕체·명조체와 로마자 및 시스템 기본 글꼴을 Noto Sans JP로 교체합니다. 읽기 어려운 명조체도 가독성 높은 글꼴로 바뀌므로 긴 글도 편안하게 볼 수 있습니다.

・고정폭·코드 → UDEV Gothic JPDOC
  사이트가 지정한 고정폭 글꼴이나 코드 표시 부분을 UDEV Gothic JPDOC로 교체합니다. 기술 블로그의 코드 블록 등도 읽기 쉬워집니다.

  UDEV Gothic JPDOC는 탁점·반탁점(「バ」와 「パ」 등)을 구별하기 쉽고, 영숫자(「1」과 「l」, 「0」과 「O」)도 분명하게 구분되는 고정폭 글꼴입니다.

・교체 글꼴에 포함되지 않은 문자(아랍 문자나 태국 문자 등)는 브라우저가 사이트가 지정한 원래 글꼴로 자동 전환하여 표시합니다.

글꼴이나 두께를 직접 고르고 싶다면, 10종의 글꼴 중에서 선택할 수 있는 자매 버전 「눈이 편한 글꼴 교체」를 이용해 주세요.

사용 방법

1. 설치하면 지원하는 사이트에서 자동으로 교체가 시작됩니다.
2. 끄고 싶을 때는 브라우저 도구 모음(확장 프로그램 메뉴)에서 팝업을 열어 스위치를 전환합니다.
3. 켜기/끄기를 전환한 뒤에는 열려 있는 페이지를 새로고침하면 반영됩니다.

번들 글꼴은 모두 확장 프로그램 패키지에 포함되어 있으며, 글꼴을 외부에서 불러오지 않습니다.
