置換の対象と考え方

置換対象
MS ゴシック / メイリオ / Yu Gothic / システムフォントなど、読みづらい指定を狙い撃ち
選べる書体
本文用 6 種類 + 等幅用 3 種類
フォールバック
置換フォントがカバーしない文字は、元サイト指定の書体へブラウザが自動で戻す
除外サイト
Google ドキュメント / Figma / VS Code for the Web など、レイアウトが崩れやすいサービスを既定で除外
バリアント
選択式の「目に優しいフォント置換」と、Noto Sans JP 固定の「NotoSans へ置換するやつ（改修型）」

サイト側が意図した装飾フォントには触れないため、見た目を保ったまま本文だけが読みやすくなります。

01

拡張機能を入れる

インストールした時点から、対象フォントの置換が始まります。

02

書体を選ぶ

ポップアップから本文用・等幅用の書体を選択。設定は自動保存されます。

03

必要な時だけ止める

トグルボタンで、サイトごとに気になるときだけ無効化できます。

FEATURES

崩さないために、
触らない場所を決める。

エディタや作図サービスなど、フォント指定が意味を持つサイトは既定で除外しています。置換が邪魔になる場所では、そもそも動きません。

  • 本文 6 種・等幅 3 種から選択して自動保存
  • ページ表示速度に影響しないよう最適化
  • レイアウト重視のサービスを既定で除外

DESIGN PRINCIPLES

TARGETED

狙ったものだけ置換

全フォント置換ではなく、読みづらい指定だけを対象にします。

FAST

表示を遅くしない

ページ描画に影響しないよう、置換処理を最適化しています。

LOCAL

設定は端末内だけ

選んだ書体は端末に保存され、外部へは送信されません。
